# perle-minig

Port of the Pearl miner's CUDA compute backend to a bit-exact Apple Metal
backend on M1 Max. See `Plan.md` for the build plan, `CONTEXT.md` for the
glossary, and `docs/adr/` for the decisions and their reasoning.

**This repo is private and must stay private** — the dev fee is removed under
upstream's personal-use exemption. See `docs/adr/0003-private-repo-and-no-dev-fee.md`.
